第三代版本
git init 文件初始化
git status 查看文件的追踪情况
git add **.txt 添加文件
git commit -m'**'  提交文件
git reset HEAD 将提交到暂存区待提交的文件进行撤回
git diff HEAD -- **(文件名)  查看当前提交与上一版本的不同
git log -x --pretty=oneline 将日志按行展示仅展示x行
版本回退:
git reset --hard HEAD^ 回退到上一版本，有几个^就回退几个版本
git reset --herd HEAD~n 回退n个版本
版本回溯：
git reset --herd +版本id前6位  回溯到这个id的版本
版本误删除
git checkout --+文件名称 将已提交到git的文件进行恢复到工作区
删除操作
git rm 文件名


提交远程仓库操作
git push -u origin +线路名称 将已commit的文件提交到远程仓库指定的线路名称中

git分支操作
git checkout branchname  切换到指定分支去
git branch 查看所有分支
git checkout -b new-branch 创建新分支并切换到新分支
git merge branch 合并分支
git branch -d branchname 删除分支


分支的push与pull操作

git branch -a 查看远程及本地分支
git push origin branch-name 推送本地分支到远程
git checkout -b 你的本地分支name origin/远程仓库指定分支name 拉取远程指定分支并在本地创建分支
git fetch 获取远程仓库最新分支情况

标签管理

git tag tag-name 新添标签 默认为head
git tag -a tag-name -m 'xxx'添加标签并指定标签描述信息
git tag 查看所有标签
git tag -d tag-name 删除本地标签
git push origin tag-name 推送本地标签到远程
